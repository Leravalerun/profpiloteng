## 🎯 Как использовать (5 минут)

### Шаг 1: Подключить движок

В любой симулятор добавьте:

```html
<!-- В <head> -->
<script src="simulator-game-engine.js"></script>
```

### Шаг 2: Инициализировать

```javascript
// В начале скрипта симулятора
const game = new SimulatorGameEngine();

// Загрузить сохраненный прогресс
game.loadProgress();
```

### Шаг 3: Использовать в задачах

```javascript
// При завершении задачи
function completeTask(taskId, userAnswer, correctAnswer) {
  // Оценить ответ
  const stars = game.evaluateAnswer(taskId, userAnswer, correctAnswer);
  
  // Записать результат
  game.rateTask(taskId, stars, 'Great job!');
  
  // Если день завершен
  if (allTasksComplete) {
    game.completeDay(dayNumber);
  }
}
```

### Шаг 4: Начать день

```javascript
// В начале каждого дня
game.startDay(); // Для отслеживания времени (speed runner achievement)
```
