📚 SQL for Data Cleaning

SQL is essential for data analysts. Here's how you'd check for missing values:

-- Check for missing values
SELECT 
    COUNT(*) as total_rows,
    COUNT(customer_id) as non_null_ids,
    COUNT(purchase_date) as non_null_dates,
    COUNT(*) - COUNT(customer_id) as missing_ids
FROM customer_data;

-- Find duplicates
SELECT customer_id, COUNT(*) as count
FROM customer_data
GROUP BY customer_id
HAVING COUNT(*) > 1;

💡 Pro Tip: Always start with data quality checks. Missing values can lead to incorrect conclusions. Common issues: nulls, duplicates, inconsistent formats, and outliers.

🛠️ 2:00 PM - Data Cleaning Task

Lisa: "I've identified some data quality issues. Here's what needs to be fixed:"

📋 Data Issues Found:

  • • 1,200 records with missing purchase_date
  • • 350 duplicate customer_id entries
  • • Negative values in 'amount' column (should be positive)
  • • Age values over 120 (likely data entry errors)

💻 Cleaning Steps:

# Remove duplicates
df = df.drop_duplicates(subset=['customer_id'])

# Handle missing dates
df = df.dropna(subset=['purchase_date'])

# Fix negative amounts
df['amount'] = df['amount'].abs()

# Remove invalid ages
df = df[(df['age'] >= 18) & (df['age'] <= 100)]
